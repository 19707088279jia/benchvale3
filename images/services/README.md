# Services visual assets

These 12 local PNGs are original AI-generated placeholder photography created for the four-page Services redesign. They are not external hotlinks and do not depict guaranteed ChromVale inventory, facilities, testing, certifications, or document availability.

## Asset roles

- `hplc-column-hero.webp` — shared HPLC column hero visual
- `column-family.webp` — column selection / family visual
- `specification-matching.webp` — column and specification review
- `documentation-set.webp` — technical documents and chromatogram
- `chromatogram-review.webp` — application / chromatogram review
- `shipping-package.webp` — professionally packaged laboratory shipment
- `quality-inspection.webp` — visual column inspection
- `quote-checklist.webp` — quotation and requirements checklist
- `coa-document.webp` — generic structured technical-document visual
- `serial-lot-label.webp` — serial, lot, and barcode-style label visual
- `care-use-guide.webp` — care and installation guide visual
- `shipment-review.webp` — visibly damaged shipment review visual

## Replacement guidance

Before production launch, replace these placeholders with owned, approved ChromVale photography where possible while retaining the filenames and wide crop. Priorities are the hero column image, actual column-family images, approved manufacturer documentation, product labels, and real shipping packaging. Do not introduce readable fictional specifications, certifications, QC results, or manufacturer branding.

## Generation prompt set

The built-in image generator was directed to create wide, photorealistic Canadian B2B chromatography visuals with a bright white laboratory palette, stainless-steel HPLC columns, restrained navy/teal accents, generous crop-safe areas, no logos, no readable claims, no certificates, no prices, and no competitor identifiers. Individual prompts varied the subject among column families, dimension review, document sets, chromatograms, product packaging, inspection, quotation checklists, serial/lot labels, care guides, and shipping-damage review.
