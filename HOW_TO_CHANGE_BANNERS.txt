CHROMVALE HOMEPAGE BANNERS — QUICK REPLACEMENT

The four current banner files are inside the images folder:
  banner-general-lab.svg
  banner-analytical.svg
  banner-liquid-handling.svg
  banner-procurement.svg

FASTEST METHOD (no HTML editing):
1. Prepare your new banner image. Recommended size: 1600 x 650 px (or similar wide ratio). JPG, PNG, WebP or SVG all work.
2. Rename your replacement image to EXACTLY the same filename as the banner you want to replace.
   Example: replace banner-general-lab.svg with a new file also named banner-general-lab.svg.
3. In GitHub, open the images folder, delete the old image, then upload the new file with the same name.
4. Commit changes. GitHub Pages normally updates within a few minutes.

If your new image is JPG/PNG/WebP instead of SVG, either rename it and change the extension in index.html, or use the HTML method below.

HTML METHOD:
Open index.html and search for: images/banner-
Change the src path to your new filename, for example:
  images/dlab-hotplate-banner.jpg

AUTOPLAY SPEED:
Open script.js and search for: 5000
5000 = 5 seconds. Change to 7000 for 7 seconds, etc.

NOTE:
The slider now uses a horizontal sliding transition (not a fade) and keeps autoplay running even when the mouse is resting over the banner.
